# Personal Reminders Bot

Telegram-бот для управления персональными напоминаниями с поддержкой повторяющихся задач.

## Возможности

- Создание одноразовых и повторяющихся напоминаний (ежедневно, еженедельно, ежемесячно, ежегодно)
- Просмотр задач на сегодня и всех активных задач
- Редактирование и завершение задач
- Автоматические уведомления в назначенное время
- Интерактивный календарь для выбора даты

## Технологии

- Python 3.12
- python-telegram-bot
- SQLite
- asyncio

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd personal_reminders
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` и добавьте токен бота:
```
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

4. Запустите бота:
```bash
python main.py
```

## Структура проекта

- `main.py` — точка входа приложения
- `bot_handler.py` — обработчики команд и сообщений Telegram
- `task_manager.py` — логика управления задачами
- `database_manager.py` — работа с базой данных SQLite
- `scheduler.py` — планировщик напоминаний
- `task.py` — модель данных задачи

## Использование

После запуска бота используйте команду `/start` в Telegram. Бот предложит интерактивное меню для:
- Добавления новых напоминаний
- Просмотра задач на сегодня
- Просмотра всех задач
- Редактирования и завершения задач
